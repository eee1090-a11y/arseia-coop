# 아르세이아의 견습생 · 월드 확장 설계서

새 지역 5곳, 지역 사이 새 연결 8곳, 지역 던전 24곳, 지역 마을 12곳의 퀘스트라인, 2막 메인 이야기를 정리했습니다. 게임 코드가 바로 읽을 수 있는 데이터는 `code/` 폴더에 있고, 실제로 게임에 넣는 일(조립·QA·배포)은 메인 스레드가 합니다. 전사의 어그로·탱커 스킬은 「v18 전사·궁수 사전 설계」 스레드가 맡고 있어 여기에는 없습니다.

## 2. 세계 지도
```

                          |
 [서리바람 고원 34]* — [북부 빙원 36] — [망각의 협곡 38]*
          |                |                  |
   [고목의 숲 26]  —  [아르세이아 남부]  —  [황금 평원 24]
                           |                  |
                   [바람의 황야 29]*  —  [붉은 사막 32] — [타말 정글 40] — [폭풍 절벽 44]*
                                                               |                 |

```
`*` 새 지역. 숫자는 지역 시작 레벨. 새 연결 덕분에 남부↔평원↔협곡↔빙원, 남부↔숲↔고원↔빙원, 남부↔황야↔사막↔평원, 정글↔절벽↔균열↔군도가 각각 한 바퀴로 돕니다.

## 5. 마을 퀘스트라인 (지역 마을 12곳)
마을마다 의뢰인 3명과 동네 사람 1명이 새로 생깁니다. 흐름은 같습니다: 동네 문제 → 채집이나 이웃 지역 배달 → 얕은 던전 정리 → 지역 우두머리 토벌(유니크·세트 장비 보상) + 매일 의뢰 하나. 이웃 지역 마을로 물건을 전하는 배달이 여섯 번 있어서, 새로 이어진 길을 따라 움직이게 됩니다. 스킬 포인트·능력치 포인트는 주지 않습니다(스노우볼 방지).

| 마을 | 연속 의뢰 | 매일 |
|---|---|---|
| 골드미어 | 수확 수레를 지켜라(25) → 풍차 날개를 묶을 갈대(26) → 곡물굴의 긁는 소리(28) → 폭풍들판의 왕(33) | 밀밭 사이의 늑대 |
| 엘드홀트 | 야영지 불빛 지키기(27) → 고목 수액 연고(28) → 썩은 뿌리의 근원(30) → 잠들지 못한 수호자(35) | 포자 주머니 모으기 |
| 까마귀샘 | 양 우리를 노리는 들개(30) → 까마귀 깃펜 꾸러미(31) → 선돌 아래의 안개 왕비(33) → 돌무덤 거인(38) | 까마귀들의 잠 |
| 사하르 오아시스 | 대상길의 붉은 전갈(33) → 샘을 맑히는 모래 백합(34) → 샘으로 내려오는 죽은 자들(36) → 모래 여왕의 대상길(41) | 모래 왕의 몰약 |
| 바람목 산채 | 산을 버린 자들(35) → 서리 백리향(36) → 은광의 목소리(38) → 천둥뿔이 울 때(42) | 치즈 시렁 지키기 |
| 프로스트헤임 | 바다에서 걸어 나온 것들(37) → 불에게 보내는 얼음(38) → 우는 얼음굴(40) → 빙원의 군주(44) | 장작길 트기 |
| 먼지문 | 도둑맞은 발굴 도구(39) → 거인의 톱니바퀴(40) → 거인의 보물고(42) → 성문의 마지막 파수꾼(47) | 우물 곁의 먼지 회오리 |
| 타말 신전촌 | 흉내 내는 북소리(41) → 달빛 덩굴꽃(42) → 덩굴 삼킨 신전(44) → 북소리를 삼키는 그림자(49) | 비단뱀 허물 모으기 |
| 갈매기 등대 | 찢긴 그물(45) → 폭풍 일지 사본(46) → 꺼진 등대(48) → 폭풍의 화신(53) | 벼랑길 비룡 쫓기 |
| 엠버홀드 | 성벽을 갉는 것들(47) → 잿더미 위의 초록(48) → 옛 대장간 되찾기(50) → 용암을 부르는 군주(55) | 용암 핵 모으기 |
| 펄 하버 | 산호 게 껍데기(53) → 바다뱀 독주머니(54) → 난파선 무덤(56) → 바다 저편의 노래(59) | 부두로 기어오르는 익사자 |
| 마지막 등불 | 등불을 갉는 그림자(55) → 빛이끼 기름(56) → 돌아오지 않은 순찰대(58) → 등불을 노려보는 눈(59) | 등불 기둥 지키기 |

아르세이아 남부 마을 네 곳은 이미 1막과 v17 마을 의뢰가 있어서 이번에는 더하지 않았습니다.

## 6. 2막 「갈라진 문」 (메인 이야기)
1막 끝에 대마법사 엘리안이 「문틈으로 먼 땅의 기운이 흘러든다」고 했던 이야기를 이어 갑니다. 모르가스가 연 문에 금이 가서 「문 조각」이 여러 지역으로 흩어졌고, 그 조각을 품은 자들이 각 지역 깊은 던전에서 힘을 키우고 있습니다.

아르덴(엘리안) → 골드미어: 폭풍 첨탑(Lv33) → 사하르: 붉은 둥지(41) → 프로스트헤임: 서리 왕의 전당(45) → 엠버홀드: 화산의 심장(55) → 갈매기 등대: 비룡 둥지(53) → 마지막 등불: 균열 아래 회랑(58) → 공허의 옥좌(60)의 「문 너머의 군주 엘가로스」.

13개 의뢰 중 마을 사이를 잇는 이야기 의뢰가 6개, 깊은 던전 공략이 7개입니다. 스킬 포인트는 붉은 둥지, 화산의 심장, 마지막 보스에서 1씩, 능력치 포인트는 마지막에 5를 줍니다. 1막을 이미 끝낸 캐릭터는 저장을 바꾸지 않고 바로 2막 첫 의뢰를 받습니다.

## 7. 필드 몬스터 데미지 기준 (솔로·탱커 없는 2인)
일반 필드 몬스터 한 대가 같은 레벨 캐릭터(장비 없음) 기본 생명력의 몇 %를 깎는지로 정했습니다.

| 종류 | 한 대 상한 | 예 |
|---|---|---|
| 빠른 근접 | 15% | 늑대, 표범 |
| 보통 근접 | 19% | 기사, 도적 |
| 느리고 무거운 근접 | 23% | 오우거, 골렘 |
| 원거리 | 17% | 정령, 무당 |

깊은 지역일수록 기준이 레벨당 1%씩 올라가서(레벨 58이면 1.34배) 조금씩 더 아프지만, 한두 대에 쓰러지지는 않습니다. 정예(6%)는 지금처럼 1.4배입니다. 준보스는 28%, 보스는 34%까지 허용해서 파티로 잡는 맛을 남겼습니다.

기존 지역은 한 대 피해가 황금 평원 12~22%에서 산호 군도 40~48%까지 올라가 이 기준을 크게 넘었습니다. 선택하신 대로 기존 7개 지역에도 같은 기준을 적용합니다. 후반 필드몹의 한 대 피해가 대략 절반이 되고, 체력·준보스·보스는 그대로입니다.

## 8. 깊은 던전 상급 유니크 14개
깊은 던전 12곳과 균열 아래 회랑의 보스가 각자 전용 상급 유니크를 떨어뜨립니다(예: 카르벤의 피뢰침, 하랄드의 서리 왕관 조각, 사라쿠스의 심장불, 셀레스의 깃털 망토). 「모든 마법 레벨」은 마지막 보스 것 두 개에만 +1로 붙여 드물게 두었습니다.
