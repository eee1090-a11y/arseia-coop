# 소리 넣기 안내 (배경음악 · 효과음 · 고위 스킬 대사)

만든 곳: 스레드 「배경음악·타격음·고위 스킬 대사」 (2026-10-08). 이 폴더는 그 스레드 소유이고, 게임에 붙이는 일(조립·QA·배포·D:\ 복사)은 메인 스레드가 한다.
미리 듣기 페이지: https://claude.ai/artifact/NM3Jttvth5mtnPp2KkgTmr (audio.js를 그대로 씀)

## 파일
| 파일 | 하는 일 |
|---|---|
| `audio.js` | 게임 조각. 효과음 합성, 배경음악 재생·전환, 대사 말풍선, 「소리 ♪」 설정 창(음악·효과음 음량, 대사 켜고 끄기, 음악 출처) |
| `lines.js` | 5위계 이상 스킬 118개의 대사 (`SKILL_LINES`, 스킬 id가 키). 마법사는 주문 + 룬 영창(s.chant), 사제는 기도 + 원래 있던 짧은 기도 |
| `music/*.mp3` | 배경음악 10곡 (MP3 72kbps, 합계 8.35MB). 곡: title, town, field, forest, snow, desert, sea, dark, dungeon, boss |
| `music-credits.json` | 곡마다 제목·작곡가·라이선스·원본 주소·받은 곳·편집 내용·게임 안 출처 문구 |
| `make-music-index.cjs` | `music-credits.json` → `music-index.js`(게임 조각, `MUSIC_INDEX`). `--embed`면 곡을 base64로 넣는다 |
| `music-index.js` | 위 스크립트가 만든 파일 (파일을 따로 두는 방식) |

효과음은 파일이 없다. 전부 Web Audio로 그 자리에서 합성한다.

## 빌드 순서
`build.sh`의 목록에서 `shop.js` 뒤, `qa.js` 앞에 세 개를 넣는다.
```
... notes.js shop.js lines.js music-index.js audio.js qa.js b5.js
```
audio.js는 기존 함수를 감싸기만 한다(cast.js의 `{const _u=update;update=...}`와 같은 방식). 규칙·숫자·저장은 바꾸지 않는다.
감싸는 함수: castFx, hurtE, killFx, hitPlayer, gainXp, pickup, usePotion, loadRegion, enterDungeon, leaveDungeon, update, render.
설정은 `localStorage['arseia-audio']` 한 키에만 쓴다. 캐릭터 키는 읽지도 쓰지도 않는다.

## 배경음악을 싣는 두 방법
**가. 넣기(권장, 사용자가 지금처럼 game.html 하나만 올리면 됨)**
```
node make-music-index.cjs --embed --out=<소스폴더>/music-index.js
```
game.html이 약 11.2MB 커진다. v5 스냅숏으로 만든 시험 빌드가 12.7MB(16MB 한도 안)였고, 시작 화면 곡 → 마을 곡 전환과 60초 실행에서 오류 0.

**나. 따로 두기 (HTML은 작고 곡은 필요할 때만 받음)**
`node make-music-index.cjs` 그대로 두고, `music/` 폴더를 게임 HTML 옆의 `audio/music/`에 같이 올린다.
- Artifact: publish할 때 `files`에 `audio/music/<곡>.mp3` 10개를 같이 넣는다.
- 같이 하기 서버(Render): server.js가 지금은 `/`만 내주므로 `/audio/music/*.mp3`를 내주는 줄이 필요하고, 사용자가 GitHub에 폴더도 올려야 한다.
- 다른 위치면 게임보다 먼저 `window.ARSEIA_AUDIO_BASE='경로/'`를 둔다.

## 곡 배치
| 곡 | 쓰는 곳 |
|---|---|
| title | 시작 화면(캐릭터 선택) |
| town | 마을 안전 지대와 집 안 (`inSafe`, `IN`) |
| field | home, plains, moor |
| forest | forest, jungle |
| snow | ice, highland |
| desert | desert, canyon |
| sea | sea, cliffs |
| dark | lava, abyss |
| dungeon | 던전 안 (`DG`) |
| boss | 화가 난 보스가 720 안에 있을 때 (들어갈 때 포효 소리) |
새 지역은 `audio.js`의 `BGM_REG`에 한 줄 더하면 된다. 0.5초마다 상황을 보고 바뀌며, 바뀔 때는 2초(보스는 0.6초) 동안 겹쳐 넘어간다.

## 대사
- 5위계 이상 마법을 쓰면 머리 위 말풍선(주인공을 따라다님). 8·9위계는 두 줄로 나눠 차례로 뜬다. 마법사는 마지막에 룬 영창 「카스 벨 엔테!」가 뜬다.
- 시전 시간이 있는 마법은 외우기 시작할 때 대사와 차오르는 소리가 나고, 끊기면 말풍선이 사라진다.
- 목소리(기계 음성)는 없다. 사용자가 들어 보고 시스템 안내처럼 어색하다고 해서 뺐다(2026-10-08 13:44). 다시 넣지 말 것.
- 연달아 쓰는 마법(재사용 3초 미만)은 같은 마법 9초에 한 번, 전체 4초에 한 번만 말한다.
- 같이 하기에서 동료의 고위 마법은 그 동료 머리 위에 말풍선이 뜬다.
- v18에서 이름·영창이 바뀌어도 id가 같으니 이 표는 그대로 쓴다. 전사·궁수 대사가 필요하면 같은 표에 id로 더하면 된다.

## #qa
- #qa에서는 파일로 된 음악은 받지 않는다(qa-run.cjs는 HTML만 내주므로 404가 콘솔 오류로 잡히기 때문). 넣기 방식(data:)이면 #qa에서도 음악을 읽는다.
- qa.js 블록 안에 아래 점검을 하나 더하면 된다. 고위 스킬 대사가 빠짐없는지, 모든 지역에 곡이 있는지 본다.
```js
qT('소리','고위 스킬 대사와 지역 곡이 빠짐없음',()=>{const bad=AUDIO_QA();qOk(!bad.length,bad.slice(0,5).join(', '))});
```

## 이 스레드에서 확인한 것 (v5 스냅숏 12:28 + 소리 조각)
- 빌드 BUILD_OK, `node --check` 통과.
- 전체 #qa 309개: 소리 넣은 판 308 통과, 넣지 않은 판도 308 통과. 둘 다 같은 1개(「라이트 레인」 적중)만 실패해서 소리 때문이 아니다. 따로 돌리면 둘 다 150/150 통과라, 무작위에 따라 흔들리는 시험으로 보인다. 콘솔 오류 0.
- 소리를 실제로 켠 상태(자동 재생 허용)에서의 성능: 50마리 전투 평균 41~45ms, 9위계 연속 31~33ms. 넣지 않은 판(42ms, 33ms)과 차이 없음.
- 효과음 16가지 모두 오류 없이 울림, 동시에 울리는 소리는 26개로 제한.
- 헤드리스 Chromium은 AAC(m4a)를 못 읽어서 곡을 MP3로 바꿨다. MP3는 모든 브라우저에서 읽힌다.

## 라이선스 메모
- 9곡은 CC0 또는 CC-BY. 사막 곡 「Mirage」(0 A.D., Wildfire Games)만 CC-BY-SA 3.0이라 자르거나 음량을 바꾸지 않고 형식만 바꿨다. 대신 재생할 때 +4.6dB(`gain`)를 준다.
- CC-BY 곡은 출처를 보여야 한다. 「소리 ♪」 창 아래에 모든 곡의 출처가 늘 보인다. 패치노트나 도움말에도 한 줄 넣어 두면 좋다.
- 던전 곡 「Cave Theme」은 Flare 저장소의 파일인데, 작곡가 Brandon Morris가 OpenGameArt에 CC0로 올린 곡이다. 파일 크기가 OGA 것과 달라서(다시 인코딩된 것으로 보임) 같은 곡이라는 것은 추정이다.
