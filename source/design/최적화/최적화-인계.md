# Optimization handoff (for the main thread)

Measured on v17 source (`rpg/src/v5`, copied to `work/base`). Prototype = `work/opt2` (base + 2 patches). rpg/src was not touched.

## Ready patches (graphics-only, no rules/numbers/hit/save changes)
- `patch-ground-iso.diff` (ground.js): ready chunks are re-baked once into a screen-space diamond canvas (`isoBlit`) and blitted per frame at identity transform (integer px). LRU of 28 iso canvases; falls back to the old transformed draw if isoBlit returns false. Covers dungeon floors too (drawDungeonFloor -> drawGround).
- `patch-hud-15hz.diff` (b5.js): `updateHud()` runs at 15 Hz from the rAF loop (`hudT`).
- QA: full #qa on opt2 = 316/316 pass, real localStorage access 0 (`qa-opt2-report.md`). QA perf vs v17 report: town 35.3->33.9, townWarm 30.1->24.5, fight50 42.7->36.3, rank9 35.3->25.3 ms.
- Screens: `shots/` (pc + 390x844 dpr3, paused, seeded RNG): mean abs diff 0.4-1.6/255, no seams.

Ablation (v17, ms removed when part is off; town/fight): ground 21/17, decor 13/2, light 6/5, hud 4/3, monsters ~0/4, parts/projs/impacts 1-3 each. Software-canvas profile (#qa mode): drawMon+mPart save/restore ~35% of frame -> whole-monster frame baking is the fix if low-end devices matter.

## Other findings
- Ground bake (paintGround) still eats 3-4 ms/frame of main thread for several seconds after moving/teleport (budget 4 ms, 24 ms when chunks missing) -> Web Worker + OffscreenCanvas candidate (B3).
- audio.js BGM keeps up to 4 decoded AudioBuffers (2-2.5 min stereo = ~40-50 MB each) -> cap 2 or stream via <audio>+MediaElementSource (B1).
- update() scales fine: 50/100/200/400 enemies = 0.24/0.45/0.85/2.48 ms. Decor ~1300-1850 per region, linear scan OK.
- Co-op snapshot: ~2 KB per snap at 15 Hz (~30 KB/s per guest) in field regions; fine.
- Load: 0.87 MB html, DOM interactive ~1.0 s.

## Tools (tools/)
- `fps.cjs GAME.html [--scenes=town,fight,r9] [--secs=6] [--off=ground,hud,...] [--prof] [--dpr=1]` real rAF timing; `--off` needs the `work/abl` build (flags in b4/b5).
- `prof.cjs GAME_QA.html --only=regex` CPU profile of #qa subset (needs `build-qa.sh` map file).
- `shot.cjs A.html B.html OUTDIR` paused, seeded before/after screenshots.
- `scale.cjs GAME.html` load time, update() scaling, decor counts.
